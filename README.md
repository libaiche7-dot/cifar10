# CIFAR-10 Classification

Undergraduate research onboarding project, Zhang Cong Lab, Shandong University.

## Structure

- `configs/` hyperparameters, one YAML per experiment
- `src/data.py` dataset and dataloaders
- `src/model.py` network definition
- `src/engine.py` training and evaluation loops
- `src/utils.py` seeding, checkpointing, metrics
- `train.py` entry point
